# Foxmaid

A friendly Mermaid diagram editor and viewer for the classroom, and a sibling to [FoxEd](https://github.com/colourverse/Foxed).

**Try it live: https://colourverse.github.io/Foxmaid/**

Or open `index.html` in a browser. It is one self-contained file. It loads CodeMirror and Mermaid from jsdelivr, and fonts from Google Fonts.

## Features

- Mermaid editor with syntax highlighting, line numbers, bracket matching and Ctrl+/ comments
- Live redraw as you type, or Draw / Ctrl+Enter
- Error card in plain language that points to the exact editor line
- Cheat sheet that follows the diagram type; click an entry to insert it
- 13 examples: flowchart, sequence, class, state, ER, Gantt, pie, mind map, timeline, git graph, journey, quadrant, XY chart
- Pan and zoom canvas (scroll, drag, pinch), Fit, full screen
- Mermaid colour themes and a "Sketchy" hand-drawn look
- Export as PNG, SVG or Markdown; copy code, SVG or a ```mermaid block; open .mmd/.txt/.md files
- Multiple diagrams saved in the browser (localStorage), light/dark theme, phone layout
